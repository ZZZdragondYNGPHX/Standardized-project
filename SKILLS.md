# Skills Index

This file routes agents to active Skills. It is not a copy of Skill contents.

## Loading rule

Load a Skill only when the user explicitly requests it or the current approved Plan requires it. Read only the relevant Skill directory.

## Active Skills

No active Skills are installed in this template repository.

## Adding a Skill

For each Skill, record:

- name;
- purpose;
- when to use it;
- directory/path;
- upstream repository and source path when third-party;
- upstream commit/tag/version;
- whether local modifications exist.

The `_template-skill/` directory is a structural template and must not be treated as an active Skill.
