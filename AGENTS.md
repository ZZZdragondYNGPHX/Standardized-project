# Local Agent Instructions — skills

This workspace contains AI Skill assets.

## Fast path

- Read `SKILLS.md` first when a task actually requires a Skill.
- Load only the Skill named by the user or required by the approved Plan.
- Do not scan every Skill “just in case.”
- Preserve upstream repository/path/version or commit metadata for third-party Skills.
- Keep imported Skill content separate by top-level directory.
- Prefer direct local file/Git operations.
- Protect unrelated dirty changes.

Read `docs:README.md` before changing Skill-governance structure or repository-wide routing rules.
